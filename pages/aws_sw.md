#### Motivation

My [AWS dashboard](https://d15fq1gbb0cw9c.cloudfront.net/) provides access to NASA OMNIWeb and the NASA DONKI catalog to enable historical data exploration, superposed epoch analyses of DONKI events, and a simplistic machine learning sandbox for storm signatures.

Source code for the full AWS stack is publicly available in the [Github repo](https://github.com/justinelfritz/aws-spaceweather-analytics).
